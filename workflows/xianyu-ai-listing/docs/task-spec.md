# Task Spec

## 背景和目标

REQ-001: 继续为闲鱼账号挖掘 AI 方向可上架需求，保持账号主线为「AI 工作流 / AI 部署 / AI 图片视频交付」。

REQ-002: 使用最新 Agent Team 三窗口方法完成本轮工作，至少沉淀需求分析、实现记录、验收记录。

REQ-003: 基于 Jina 外部资料与闲鱼站内搜索信号，生成 Round 5 机会榜，并选择 1 个可复利、可交付、风险可控的商品进入发布流程。

REQ-004: 选中商品需要完成原创商品图、中文叠字、发布文案、机器可读发布配置，并使用已登录的 Goofish 网页发布。

REQ-005: 发布完成后记录商品链接、截图、配置、图片和需求证据，方便后续复盘。

## 本次范围

TASK-001: 挖掘 8-12 个新的 AI 需求关键词，优先覆盖近期开源工具、AI 图像服务、AI 视频工作流、工具站/SaaS 交付。

TASK-002: 使用 Jina 搜索与已登录闲鱼站内搜索采集证据，记录来源、想要数/价格/重复商品、买家痛点和风险点。

TASK-003: 使用 WORTH 评分输出 Round 5 机会 JSON 与 Markdown 排行榜。

TASK-004: 选择最高优先级商品包，生成 5-6 张 1:1 商品图，底图优先使用 RunningHub Image2 低价通道，中文信息本地叠加。

TASK-005: 生成发布文案、价格梯度、买家需提供内容、交付边界和 `publish_config.json`。

TASK-006: 使用 Goofish 发布 helper 填写、上传、检查并发布商品。

## 本次不做

NON-001: 不做自动私信、批量骚扰、刷曝光、绕风控、接码、账号买卖等平台违规动作。

NON-002: 不提供未授权换脸、公众人物仿冒、隐私窃取、情感操控、侵权素材处理等高风险服务。

NON-003: 不复制其他卖家的原图或原文，只借鉴需求信号和卖点结构。

## 业务规则

RULE-BIZ-001: 优先选择复利资产高的商品，即能沉淀 SOP、FAQ、图片模板、交付脚本、案例库或后续变体。

RULE-BIZ-002: 首发价格需要有低门槛入口和高客单升级项，不能只做一次性低价体力活。

RULE-BIZ-003: 商品图必须让买家一眼知道「解决什么问题」「交付什么」「怎么收费/怎么开始」。

RULE-BIZ-004: 发布类目优先使用网页端已验证可用类目：`AI图文工具/服务`、`AI视频工具/服务`、`AI提效工具`。

## 权限规则

RULE-AUTH-001: 仅使用本地已配置的 Jina、RunningHub、已登录 Goofish 会话，不在文档或回复中暴露 API Key。

RULE-AUTH-002: 最终发布动作基于用户已明确要求「帮我发布」执行；若页面要求扫码或会话失效，需要停下让用户登录。

## 数据规则

RULE-DATA-001: 需求雷达输出保存到 `output/demand_radar/round5_2026-05-22/`。

RULE-DATA-002: 商品包输出保存到独立 `output/<pack_name>/`，至少包含图片、提示词、发布配置、发布结果。

RULE-DATA-003: 三窗口过程记录保存到 `docs/agent-team/runs/2026-05-22-round5-xianyu-demand-publish/`。

## 影响范围

本次主要影响新增文档、需求雷达输出、商品包图片和发布配置，不修改既有已发布商品记录。

## 推荐实现步骤

TASK-007: 需求窗口给出搜索关键词与候选方向。

TASK-008: 实现窗口执行 Jina 搜索、闲鱼站内搜索、WORTH 打分、商品包制作与发布。

TASK-009: 验收窗口核对 AC、发布结果与证据文件。

## 验收标准

AC-001: 存在 Round 5 机会 JSON 和 Markdown 排行榜，且至少包含 5 个候选机会。

AC-002: 排行榜中每个机会都有 WORTH 分数、证据摘要、商品形态、价格建议、风险边界和复利评级。

AC-003: 被选中发布的商品包至少包含 5 张原创商品图、`publish_config.json`、发布文案和图片提示词。

AC-004: 商品文案明确买家需要提供什么、交付什么、价格梯度、修改次数和不接内容。

AC-005: 商品成功发布后存在 `published_result.json`，其中包含最终 URL 或平台返回的可核验状态。

AC-006: `worker-report.md` 记录实现过程、自测结果、未覆盖项与风险。

AC-007: `review-report.md` 对 AC-001 至 AC-006 逐项给出 PASS / FAIL / BLOCKED 证据。

暂无。用户已要求继续挖掘并帮忙发布。
