# Image2 故事板视频提示词

## 使用范围

本 skill 保存故事板的具体生产规格，不再作为全局 AGENTS 硬规则。只有当 `prompt-skill-router` 或用户明确把任务路由到故事板时使用。

触发范围：`故事板`、`分镜板`、`电影制作板`、`视觉规划表`、`storyboard`、`story board`、AI 视频故事板、故事片段转故事板图片、故事板转 Seedance2/SD2 视频提示词。

普通 AI 视频、Seedance2 镜头、Image2 首帧、抽卡挑片、后期剪辑、声音字幕和质量诊断，默认先走 `ai-video-fundamentals-skill`；只有明确需要故事板资产或故事板转视频提示词时，才叠加本 skill。

合格故事板交付默认包含：一张 16:9 Image2 电影制作板 / 视觉规划表、至少 6 个编号故事帧（默认 8-9 个，信息量不足时不得降成 3 帧）、角色和风格参考区、道具锁定区、环境和机位路线区、灯光/情绪/音频/摄影笔记。只有故事板图已经生成并被接受后，才补写匹配的视频生成提示词。

## 汽车带货转绘下游规则

当本 skill 被 `automotive-commerce-redraw-video` 调用时，默认执行三段式：

1. 先写每个 10-15 秒生产段的 `故事板 Image2 提示词 + 对应参考图`，不写生视频提示词。
2. 再用 RH/Image2 批量生成故事板图，记录实际图片路径、参考图、prompt hash、QA/用户接受状态。
3. 最后只基于已接受故事板图写 Hi-light/Seedance2/Mimo 生视频提示词。

汽车带货故事板提示词必须只面向 Image2 模型，不得混入内部流程语言，例如 `生产段`、`PV03`、`源片范围`、`S05+S06`、`证据链`、`待生成`。这些信息只能放在表格备注或证据列里。

汽车带货故事板必须把母图/官方车图、懂车帝黄牌参考、手臂服装参考、场景参考列在提示词旁边。若用户已经指定母图，后续同一场景默认沿用母图的背景和车身状态；不得回到旧首帧、旧失败故事板或无关素材图。

本 skill 的默认产出是 **一张** 16:9 电影制作板 / 视觉规划表。  
不要默认产出两张故事板，不要默认做纯 PREVIS 黑白分镜纸。

## 高质量故事板默认四阶段工作流

用户已明确补充：高质量故事板默认不要一上来直接做正式故事板，而要先锁资产，再进制作板。

默认顺序：

1. **人物图**
2. **关键信息图**
3. **首帧图**
4. **故事板**

除非用户明确说“直接做故事板”“只要快速版”“跳过前置资产”，否则进入高质量故事板任务时，先按这四步工作。

### 阶段 1：人物图

先做会反复出现在视频和故事板里的核心人物资产，优先做多模块角色圣经图，不要直接拿一句人物描述进故事板。

- 至少锁定：脸部结构、发型轮廓、服装搭配、手势或行为习惯、远中近景识别点。
- 对于“单人长时间口播 + 多片段转场”项目，先锁固定主讲人，再考虑辅助人物。
- 人物图没通过辨识度和真实感，不进入首帧，更不进入故事板。

### 阶段 2：关键信息图

先把口播、剧情或卖点里最核心的 3-5 条信息关系做成视觉信息锚点图。

- 这些图不是正式故事板，也不是最终视频画面。
- 作用是先锁“这一段到底要说明什么”，防止故事板一开始就散。
- 信息图要像纪实视觉信息板或导演前期关系板，不要做成 PPT、扁平 infographic、科技大屏或营销海报。

### 阶段 3：首帧图

每个未来的视频段落先做 true first frame，再进入故事板。

- 首帧是真视频起点，不是海报，不是故事板，不是静态成片。
- 首帧要锁：画幅、构图、主体位置、空间关系、光线方向、动作起点、镜头运动余量。
- 对于口播项目，先做主讲人口播位首帧；B-roll 场景再按段落补首帧。
- 首帧没通过，不进入正式故事板。

### 阶段 4：故事板

只有前 3 阶段通过后，才做正式单张 16:9 电影制作板 / 视觉规划表。

故事板必须继承：

- 已通过的人物图身份锚点；
- 已通过的关键信息图逻辑；
- 已通过的首帧图起始构图和场景锚点。

不要反过来用故事板替代人物图、信息图或首帧图的职责。

### 口播型项目专用规则

如果项目形态是“单人长时间口播 + 多片段转场 / 插片”，默认这样分工：

- 人物图：先锁固定主讲人；
- 关键信息图：先锁每个论点的视觉关系；
- 首帧图：先锁主讲人口播位，再锁 B-roll 起始画面；
- 故事板：主讲人镜头做主线，B-roll 只负责解释、证明和转场，不另起一条故事线。

## 单张故事板结构

一张正式故事板必须包含这些区域：

- **共享创意指导 / 顶部栏**：标题、时长、比例、镜头数量、统一调色板、环境背景、视觉优先级。
- **角色与风格参考**：角色正面、背面、侧面、特写、放松姿态；服装、配饰、身份锚点；如果有参考图，使用参考图锁定角色。
- **道具锁定**：核心道具、材质、用途、不可变形态。
- **环境和场景设计**：主场景图、俯视示意图、角色移动路径、摄像机位置、沿路线标注的拍摄类型。
- **故事板区**：8-9 个编号帧，展示场景进展；每帧要有镜头大小、运动方式、动作和情绪推进。
- **灯光 / 情绪 / 风格备注**：光线条件、氛围、纹理、时间变化、光质变化。
- **情绪关键词块**：简洁情绪基调和主题词。
- **音频 / 音调部分**：环境声、音乐风格、声音气氛。
- **电影摄影笔记**：焦段、景别策略、运动风格、后期处理感觉、转场方法。

整体版面要连贯、电影化、专业设计，像导演预制作指南，一眼传达基调、节奏和视觉叙事。

## 导演注释颜色系统

把这套注释系统融入同一张故事板，不再单独产出 PREVIS：

- 红色箭头 = 身体运动；
- 蓝色箭头 = 摄像机运动；
- 绿色标记 = 构图 / 构图笔记；
- 橙色标记 = 光线方向；
- 紫色标记 = 歌声 / 情感强调；
- 黑色文字 = 短焦镜头笔记和面板标签。

彩色标记必须服务导演信息，不要变成装饰。

### Image2 正向提示词硬规则

用户已明确纠正：Image2 可能把负面约束当作参考元素吸收。  
因此写给 Image2 的故事板生成提示词正文必须使用正向描述：

- 用“画面呈现什么、版面包含什么、风格是什么、文字如何出现、画面优先级是什么”来约束；
- 不把“不要什么、禁止什么、避免什么、不能什么、无什么”这类负向清单写进 Image2 提示词正文；
- 质量门、失败条件、禁忌项可以用于内部审核或项目文档，但不能复制进 Image2 生成提示词；
- 必须保留完整栏目和图内文字要求，但要用正向表达，例如“清晰中文栏目、规整编号、专业制作板文字、干净单张 16:9 版面”；
- 台词只放在底部 `音频 / 音调` 栏，以制作笔记小字记录；1-9 号故事帧保持纯电影画面，只呈现人物、道具、场景、导演箭头、构图框和情绪标记，台词文字不进入故事帧内部；
- 颜色、服装、车牌、手臂状态、道具样式必须使用单一确定锚点，不使用 `A/B`、`A或B`、`深色/黑色`、`黑色或深色` 这类选择式表达；如果参考图已经确定为 `曜石黑宝马3系`、`懂车帝同款黄色车牌`、`黑色短袖T恤`、`裸前臂`，提示词全文都必须沿用这些确定词。

- 如果旧模板里含负向清单，执行时必须改写成正向版再提交给 Image2。

## 视频提示词规则

如果用户要“配套生视频提示词”或“故事板转视频”，使用 `references/video-from-storyboard-template.md`。

### 先看懂故事板

写配套生视频提示词前，必须先读懂故事板图本身，不能只套模板。先完成内部拆解：

1. 数清故事板有几格关键画面，以及每格的画面任务。
2. 识别每格里的主体：人物站位、表情、手部、道具、前景/背景、光线方向和情绪停点。
3. 找出格与格之间缺失的动作连接：眼神如何转、手如何动、身体如何靠近或后退、道具如何晃动、镜头如何推/跟/遮挡转场。
4. 找出故事板已有的台词、环境声、摄影笔记和画面完整性护栏。
5. 如果故事板图和文字提示词冲突，以故事板图为准；提示词只做关键帧调度和帧间连接。

只有完成这一步，才能写模板 A 或模板 B 的生视频提示词。

### 故事板与视频提示词的关系

用户已明确纠正：故事板和视频提示词不是两套共同描述同一画面的文案，不能互相竞争或冲突。

正确关系是：

- 故事板负责画面本体：人物长相、服装、道具、场景、构图、关键动作、情绪停点、光线和视觉风格。
- 视频提示词负责调动故事板里已经存在的画面：按故事板关键帧推进镜头，写清楚每个故事板画面之间的连接动作、过渡、镜头移动、声音和节奏。
- 不要在视频提示词里重新设计故事板没有的画面、道具、服装、场景或新动作。
- 如果视频提示词与故事板图冲突，以故事板图为准，删掉或改写提示词。
- 配套视频提示词应优先使用“从故事板画面1过渡到画面2”“保持故事板中的人物站位和道具位置”“补足两格之间的手部/眼神/脚步连接”这类调度语言。
- 可以写故事板画面编号来说明关键帧调度，但必须明确“不要把编号、网格、箭头、标签、排版生成到视频里”。
- 当模型不够贴故事板时，改用“强锚点调度”写法：明确每个时间点要贴近故事板第几格的原图构图、人物站位、道具位置、景别、光线和情绪，再写从这一格到下一格的连接动作。不要泛泛写剧情概括。
- 默认模板选择：故事板图生成后配套生视频提示词，默认使用“模板 A：强锚点调度版”。只有用户明确说“不需要太强的引导性”“弱一点”“不要这么强锚点”“用自然一点的过渡提示词”时，才改用“模板 B：画面过渡修正版”。
- 最终可复制给视频模型的正文必须完整，并且以“应该做什么”为主体。默认包含 `【成片目标】`、`【参考图/故事板使用方式】`、`【主体与场景锁定】`、`【时间轴与动作推进】`、`【镜头设计】`、`【表演与物理细节】`、`【声音设计】`、`【画面完整性护栏】`。质量门、失败条件、审核标准和额外解释留在内部，不放进正文。

### 模板 A：强锚点调度版（默认）

用途：让视频模型最大程度贴住故事板原图。适合用户说“更参考故事板原图”“引导性强一点”“不要跑偏”，也是默认配套视频提示词格式。

格式：

```text
【成片目标】
<横屏/竖屏与比例>，<时长，默认不超过 15 秒>，<单段完整镜头/多段镜头>。成片要呈现 <核心展示价值/情绪目标>，从 <起始状态> 推进到 <结尾英雄状态>，整体质感是 <电影感/商业广告感/真实抓拍感/高级展示面>。

【参考图/故事板使用方式】
```

### 模板 B：画面过渡修正版（用户要求降低引导性时使用）

用途：仍然以故事板为主，但语言比强锚点更自然。适合用户说“不需要太强的引导性”“自然一点”“别写太死”。

格式：

```text
【成片目标】
<横屏/竖屏与比例>，<时长，默认不超过 15 秒>，<单段完整镜头/多段镜头>。视频按 @故事板 的画面顺序推进，完成 <核心动作/关系/情绪闭环>，风格保持 <真实/电影感/商业展示感>。

【参考图/故事板使用方式】
@故事板 提供画面顺序、主体身份、动作方向和情绪节奏。视频生成时保留故事板的主要构图和关键停点，用自然过渡把它们连成一个镜头。

【主体与场景锁定】
主体保持 <人物身份、服装、道具、场景、光线和情绪>，空间关系和重要物件位置跟随故事板。

【时间轴与动作推进】
<时间段>：从故事板画面<N>开始，保持该画面的主要构图、人物站位和道具状态，补一个轻微进入动作。

<时间段>：从画面<N>过渡到画面<N+1>，补足两格之间的眼神、手部、脚步、道具、镜头或遮挡转场。

<时间段>：从画面<N+1>落到画面<N+2>，保持故事板里的情绪停点，并自然推进到下一格。

<继续按故事板顺序写到最后一格>。

【镜头设计】
镜头平滑推进、转向或跟随主体，保持故事板顺序和空间关系，让动作更顺、更有层次。

【表演与物理细节】
人物的眼神、手部、脚步、衣料、头发、道具和环境有自然轻动，动作连接真实可信。

【声音设计】
```

视频提示词可以按 4 秒单镜头或多段镜头拆开，但不能把故事板排版带进视频。

可复制的视频提示词正文应以正向执行重点为主，并用 `【画面完整性护栏】` 收住质量边界。不要把质量门、失败条件或审核标准放进正文。

### 故事板图生视频硬规则

当故事板图被上传为参考图、首帧或图生视频输入时，生视频提示词必须把故事板当作关键帧调度表使用。默认允许并优先写 `@故事板 第N格`、`从第N格连接到第N+1格`，这样模型才会更贴故事板原图。

正确写法：
- `0.0s：画面必须贴近 @故事板 第1格原图。<只写第1格已有画面>`
- `0.0-1.5s：从第1格连接到第2格。<只补两格之间缺失的动作连接>`
- `1.5s：画面必须贴近 @故事板 第2格原图。<只写第2格已有画面停点>`

错误写法：
- 把故事板和提示词分别写成两套互相竞争的画面描述；
- 在故事板没有的地方新增服装、道具、场景、清晰人物或大动作；
- 把 `【参考图职责】`、`【限制】`、质量门、验收标准写进可复制正文；
- 写“或、或者、A/B、可以是、也可以是、任选”这类二选一描述；
- 写成“画面展示一张故事板 / 分镜板 / 制作板”，或让视频生成网格、边框、编号、箭头、注释、标签、UI、分镜纸排版、幻灯片移动、排版动画。

内部审核时仍要检查不要生成故事板排版元素，但这类限制不要作为 `【限制】` 段放进最终提示词正文。最终正文只输出 `【基础设定】`、`【画面锚点与连接】`、`【声音】`。

每个故事板默认只对应一段视频；每段视频时长最多 15 秒，除非用户明确要求并确认更长结构。

## 质量门

故事板通过标准：

- 只有一张 16:9 制作板。
- 顶部栏、角色参考、道具锁定、环境路线、8-9 个故事帧、灯光、情绪、音频、摄影笔记都存在。
- 8-9 个故事帧能看出镜头大小、动作、情绪和推进变化。
- 场景不能过于相似，必须有远景、中景、特写、反应、动作推进和结尾画面差异。
- 角色身份和关键道具能被认出。
- 色彩和纸张风格统一，像专业导演预制作指南。
- 红/蓝/绿/橙/紫标记正确服务身体、机位、构图、光线和情绪。

### Image2 图内文字硬闸门

用户已明确纠正：故事板上该有的栏目字、镜头号、角色名、道具名、机位路线说明、灯光情绪音频摄影笔记不能消失。不能把“防止 Image2 伪字”误执行成“减少 Image2 图内文字”。

绝对规则：

1. 故事板最终成图必须由 Image2 生成；图内文字、栏目、编号、标签、箭头说明和制作板信息也必须由 Image2 生成；
2. 绝对禁止本地真实排版、本地拼板、本地加字、本地修字、本地合成后冒充故事板；
3. 不允许为了避开 Image2 伪字而减少栏目、删除镜头说明、删掉灯光音频摄影笔记，或只保留极短标题；
4. 需要完整保留：顶部共享创意指导、角色与风格参考、道具锁定、环境和机位路线、8-9 个编号故事帧、每帧镜头/动作说明、灯光/情绪/风格、关键词、音频、摄影笔记、导演注释颜色系统；
5. 如果 Image2 生成的文字伪字、乱码、缺项、不可读，必须继续用 Image2 重跑或用 Image2 图生图修正，不得改成本地排版补救；
6. 可以通过更清晰的中文短句、分区命名、参考图、版式约束、分批 Image2 生成后再用 Image2 合成来提高文字成功率，但不能降低内容完整度。

凡交付的正式故事板图缺少必要栏目字、镜头号、角色道具标注、镜头说明、灯光音频摄影笔记，或使用非 Image2 方式补字/拼板，一律判定失败，必须按 Image2-only 全内容标准重做。不要把“视频提示词里禁止复制故事板文字/网格”误执行成“故事板本身不要文字”。

必须重做：

- 生成两张故事板而不是一张；
- 做成纯 PREVIS 黑白分镜纸；
- 做成暗色电影截图合集；
- 8-9 帧场景过于相似；
- 缺少角色参考、路线图、灯光音频摄影笔记；
- 出现大量乱码、水印、假 UI；
- 视频提示词复制故事板网格、箭头、标签或排版。

## 输出纪律

- 用户要“故事板”，默认只生成一张电影制作板 / 视觉规划表。
- 用户要“提示词”，输出可复制的 Image2 故事板提示词或视频提示词。
- 用户要“交付包”，交付一张故事板图、配套视频提示词、参考职责和质量门。
- 凡是交付故事板图，配套生视频提示词必须同步给出或说明当前只交故事板。
- 不把纯文字分镜当最终交付。
